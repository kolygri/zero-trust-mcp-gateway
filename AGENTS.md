# User publication boundary

The user requires explicit permission before any change to their existing website.

- Do not modify `kolygri/kolygri.github.io`, its branches, files, Pages settings, deployments, custom domains, or DNS without first asking the user and receiving approval for the specific change.
- Do not publish this project anywhere on `kolygri.github.io`, including a project subpath, without that explicit approval. A general request to publish a different project is not permission to use this domain.
- Host the reading library on its separate Sites address. GitHub Pages for `kolygri/zero-trust-mcp-gateway-reading` must remain disabled unless the user explicitly approves changing that.
- Read-only checks are allowed. Preserve unrelated user changes.
